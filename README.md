## About the Project
This project is a product landing page created to practice visual layout composition, color harmony, typography, and front-end interactivity using **HTML**, **CSS**, and **JavaScript**.

## Features
- **Clean Navigation Bar**: Includes brand logo on the left and navigation links (`Home`, `Orders`, `Product`, `Contact`) on the right.
- **Hero Showcase**: Features the **Boston Round** organic product lineup alongside a clear value proposition and a **Shop Now** call-to-action button.
- **Balanced Color Palette**: Soft neutral card surface paired with earthy green tones that match natural skincare branding.
- **Live Preview**: Deployed on GitHub Pages for quick viewing.

## Built With
- **HTML5** – Semantic structure for header, navigation, hero content, and action controls.
- **CSS3** – Layout alignment, typography hierarchy, color styling, and button states.
- **JavaScript (Vanilla JS)** – Interactive behavior and DOM handling (`app.js`).

## What I Practiced & Notes
- **Visual Hierarchy & Spacing**: Balancing product imagery, heading scale (`Boston Round`), supporting copy, and the CTA button inside a framed layout.
- **File Organization**: Managing `index.html`, `style.css`, `app.js`, and image assets cleanly inside the repository.
- **Future Improvement**: Connecting navigation links and the `Shop Now` button to dedicated sections or interactive product views.
